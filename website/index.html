Before you begin

Common questions, direct answers.

NightScope is deliberately focused: it supports planning decisions and leaves sky-chart and hardware-control work to dedicated tools.

Is NightScope a planetarium or telescope-control application?

No. NightScope is a decision-support planner. It recommends targets, time windows and equipment context; it is not a star atlas, mount controller or substitute for safe observing practice.

Does NightScope require an online account?

No NightScope account is required. Core astronomical calculations and the celestial catalogue are local. Optional weather and environmental providers need internet access, and some offer their own credentials.

Why do Windows and Linux have different release numbers?

The portable bundles are built, audited and published independently. Windows currently has version 1.45.21; the latest public Linux package remains version 1.43.0 until a newer Linux bundle completes validation.

Where can I read the complete documentation?

Start with the multilingual user manual or explore the technical documentation in the GitHub repository.
