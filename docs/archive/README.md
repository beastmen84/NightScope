# Documentation Archive

This directory preserves historical validation records and superseded handoff
snapshots. The files remain useful as evidence, but they are not the current
operational instructions.

Use these living documents for current work:

- `docs/ARCHITECTURE.md`
- `docs/ARCHITECTURE_REVIEW_1_45.md`
- `docs/TESTING.md`
- `docs/NEXT_CHAT_HANDOFF.md`
- `docs/RELEASE_CHECKLIST.md`

Archived records should not be rewritten merely to match a newer source
version. Add a new snapshot when historical evidence needs to be retained.
